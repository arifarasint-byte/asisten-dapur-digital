# 🍳 Smart Meal Planner & Resep Keluarga v1.0

Aplikasi asisten dapur digital berbasis **Python & Streamlit** untuk merencanakan menu makan mingguan, mengelola galeri resep keluarga secara visual, serta menghasilkan daftar belanja pasar otomatis yang terintegrasi langsung dengan **WhatsApp**.

Aplikasi ini menggunakan **Microsoft Excel (`database.xlsx`)** sebagai pusat penyimpanan data, menjadikannya portable, mandiri, dan bebas biaya langganan server bulanan yang mahal.

## 🚀 Fitur Utama

- **📅 Perencana Mingguan Dinamis:** Grid interaktif 7 hari (Senin-Minggu) untuk menyusun jadwal Sarapan, Makan Siang, dan Makan Malam.
- **🥗 Galeri Resep Premium (Termasuk 50 Resep Bawaan):** Sudah dilengkapi dengan 30 resep masakan rumahan hemat dan 20 menu diet sehat rendah kalori.
- **📸 Upload Foto Masa Depan (Base64):** Menyimpan foto hasil masakan Anda sendiri langsung ke dalam file Excel dalam format teks aman (tanpa takut hilang saat server restart).
- **📲 Integrasi Cerdas WhatsApp:** Menyaring bahan yang belum Anda beli di pasar, lalu mengirimkan sisa daftar belanja tersebut langsung ke chat WhatsApp dalam 1 klik.

## 🛠️ Tech Stack

- **Framework:** Streamlit (Python)
- **Database:** Microsoft Excel (.xlsx) via Pandas & Openpyxl
- **Image Processing:** Pillow (PIL)

## 📦 Paket Penjualan Produk Digital
Jika Anda membeli lisensi aplikasi ini, Anda akan mendapatkan:
1. Source Code Utama (`app.py`, `database_helper.py`)
2. Pre-loaded Database Excel berisi 50 resep siap pakai.
3. Panduan instalasi mandiri ke Streamlit Cloud dalam 5 menit.
